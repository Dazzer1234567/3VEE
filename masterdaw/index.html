MASTERDAW - BETA

MASTERDAW is a modern, powerful DAW, finely tuned to the needs of pro mastering engineers and anyone serious about audio mastering.

  • Node-based plugin routing
  • Object-based effects, with a nested DAW inside each object
  • Mix replace tools for comparing new mixes
  • Automated export workflows
  • Optimised for analog mastering recalls
  • Automated (but optional) file management
  • Master version tracking
  • Unique automation objects
  • MIDI editing & VSTi
  • Anti-RSI interface design
  • AI agent ready (MCP inside)
  • Headless control
  • LUA & Pure Data integrated
FAQ
How much will the app cost?

The final price is not yet firm, but it will be around 300 euros. That includes a year of support, new versions and priority on your feature requests. After the first year, updates and support are 100 euros per year, and you can renew at that price whenever you like.

If you don't renew, new versions and support stop until you do. The program itself doesn't stop working: you keep the last version you received, and that version keeps getting bug fixes for 2 years. These bug fixes don't cover new hardware or new operating system versions; for those you need the current version.

How long does the beta work?

Each beta version works for one month from its release. New beta versions come out regularly, and each new one works for a month too, so download the latest one and you can keep using the beta until the full release.

What are the system requirements?

Windows

  • Windows 10 or 11, 64-bit
  • Any 64-bit Intel or AMD processor
  • An ASIO audio interface is recommended; the built-in audio device also works

macOS

  • A Mac with Apple silicon (M1 or later). Intel Macs are not supported.
  • macOS [version] or later
  • Any Core Audio device

Linux

  • 64-bit Ubuntu 24.04 or later, or a similar distribution, with a GTK 3 desktop
  • PipeWire for audio

All platforms

  • 8 GB of RAM (16 GB recommended)
  • A screen of 1920×1080 or larger
  • Plugins: VST3, including ARA plugins

What is headless control used for?

Headless means MASTERDAW can run without its screen interface, controlled by scripts or other programs instead of the mouse. That makes it possible to automate repetitive jobs, such as rendering a batch of masters in every format a client needs, or to run MASTERDAW on a separate machine in the studio and control it from another one.

What can the AI agent (MCP) integration do?

MCP (Model Context Protocol) is an open standard that lets AI assistants, such as Claude or ChatGPT, work with other programs. MASTERDAW has MCP built in, so if you use an AI assistant you can ask it to do things in MASTERDAW for you in plain language, like setting up a session, preparing exports or checking your files.

MASTERDAW itself has no AI features built in. MCP is only a connection point, so it's entirely optional, and nothing happens unless you connect an assistant yourself.
